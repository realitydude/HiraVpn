# Hira VPN — نسخه اولیه OpenVPN
سرور آماده: 2.hiragroup.tech، TCP 1194، MTU 1380. کانفیگ و CA از فایل ارسالی شما هستند. کاربر فقط نام کاربری و رمز را وارد می‌کند. این بسته شامل صفحه اختصاصی واقعی متصل به هسته OpenVPN for Android و workflow ساخت است؛ فایل APK از قبل ساخته نشده است.

## ساخت
1. یک مخزن GitHub بسازید. محتویات این پوشه را در ریشه مخزن قرار دهید؛ پوشه مخفی `.github` هم باید وارد شود.
2. در تب Actions، workflow «Hira VPN APK» را Run کنید.
3. بعد از سبز شدن، از Artifacts فایل HiraVPN-Test-APK را دانلود و ZIP را باز کنید؛ APK داخل آن روی گوشی نصب می‌شود.
4. اجازه VPN اندروید را تایید کنید و با حساب OpenVPN سرور وارد شوید.

ورود ناموفق، گواهی نامعتبر، سرور خاموش یا ناسازگاری تنظیمات نیازمند بررسی گزارش اتصال هستند. تست واقعی اتصال با حساب کاربر انجام نشده است. این نسخه برای تست است؛ برای انتشار و بروزرسانی پایدار باید کلید امضای اختصاصی ثابت تنظیم شود. امضای debug در runnerهای مختلف ممکن است تغییر کند و نصب نسخه بعدی نیاز به حذف قبلی داشته باشد.

## امنیت و محدودیت
رمز در سورس یا GitHub قرار نمی‌گیرد. هسته برای راه‌اندازی سرویس، پروفایل موقت حاوی رمز را در فضای خصوصی اپ ذخیره می‌کند؛ آن فایل رمزگذاری جداگانه ندارد. بکاپ برنامه غیرفعال و اسکرین‌شات صفحه ورود مسدود است. ذخیره امن رمز برای نسخه انتشار باید تکمیل شود. هیچ V2Ray یا ورود یکپارچه‌ای در این نسخه وجود ندارد.

بررسی نقش client certificate در سمت سرور ضروری است: فایل ارسالی فقط CA دارد؛ اگر سرور گواهی کلاینت اجباری کند، فایل تکمیلی لازم است. اعتبار گواهی و cipher در اپ دور زده نمی‌شوند.
